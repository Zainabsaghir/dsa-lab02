\# Lab 02: Static and Dynamic Arrays, Pointers and Dynamic Memory Allocation



\## Objective



The purpose of this lab is to understand static and dynamic arrays, pointers, pointer notation, and dynamic memory allocation in C++. The lab also focuses on proper memory management and identifying common memory-related errors.



\## Topics Covered



\- Static arrays

\- Dynamic 1D arrays

\- Dynamic 2D arrays

\- Pointers and pointer notation

\- Pointer arithmetic

\- Dynamic memory allocation using `new`

\- Releasing memory using `delete\[]`

\- Dangling pointers

\- Out-of-bounds access

\- Memory leaks

\- Working with 2D arrays using `int\*\*`

\- Pointers to rows in 2D arrays



\## Lab Tasks



\### Task 1



Working with arrays and pointers to understand basic pointer notation.



\### Task 2



Creating and processing a dynamically allocated 1D array using pointers.



\### Task 3



Using a pointer to a row of a static 2D array to read, display, and calculate sales totals.



\### Task 4



Creating a dynamically allocated 2D array using `int\*\*`, calculating student totals, and properly releasing all allocated memory.



\### Task 5



Expanding a dynamically allocated array by allocating a new block, copying the existing values, adding a new value, and releasing the old block.



\### Task 6



Identifying common memory errors such as out-of-bounds access, dangling pointers, and memory leaks, and correcting them.



\## Conclusion



This lab provided practical experience with arrays, pointers, and dynamic memory allocation in C++. It also demonstrated the importance of correctly allocating and releasing memory to avoid errors and memory leaks.
